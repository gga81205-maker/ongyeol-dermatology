# 온결피부과 — 포트폴리오 랜딩 페이지

가상의 피부과 병원 홈페이지를 Next.js로 구현한 포트폴리오 프로젝트입니다.
병원명·인물·연락처·주소는 모두 실제와 무관하며, 예약 폼은 서버로 전송하지 않는 데모입니다.

## 기술 스택

- Next.js 15 (App Router) · React 19 · TypeScript
- 순수 CSS (디자인 토큰 기반, 반응형)

## 주요 기능

- 1페이지 랜딩: 소개 · 진료 · 의료진 · 예약 · 안내
- 예약 폼: 진료 항목 → 달력 날짜(60일 이내) → 30분 단위 시간 → 예약자 정보
  - 평일/주말 진료 시간에 맞춘 시간대, 휴대폰 번호 자동 하이픈, 입력 검증
- 진료 목록에서 "예약 →" 클릭 시 해당 항목이 선택된 채로 예약 폼으로 이동
- 모바일 대응 레이아웃, 키보드·스크린리더 접근성 고려

## 실행

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # 프로덕션 빌드
```

## 배포

[Vercel](https://vercel.com)에서 이 저장소를 Import하면 별도 설정 없이 배포됩니다.
